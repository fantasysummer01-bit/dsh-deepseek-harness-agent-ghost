## 0.5.0 保留核心记录的插件更新

日期：2026-10-27。`npm run check` 通过；普通 Node 全量 211 项通过、2 项真实宿主测试明确跳过；`scripts/Test-Desktop.ps1` 使用本机实际 SDK，全量 213 项通过、0 失败、0 跳过。

更新相关分组覆盖界面 23 项、网络源 15 项、worker 17 项、协调器 10 项和桥接 3 项。全量结果还包含既有人格、记忆、主体、导出与卸载回归；分组数字不是独立的总验收数量。

### 验证场景

- 只有点击才检查固定 GitHub 仓库的 `main` 稳定 SemVer；固定提交后下载 Git blobs，校验哈希、字节数与缓存，拒绝重定向、不兼容声明、不安全路径及超出边界的响应。没有 Token 或定时联网轮询。
- 已是最新、下载失败可重试、重复点击、待退出状态、与卸载互斥均有覆盖；待更新仍可启动／关闭与导出，不把已排队显示为已安装。
- 下载代码、任务元数据、控制锁和五个 profile 文件的备份位于独立代码缓存。临时 helper 等待 DSH 正常退出，通过官方 CLI 切换代码；安装失败尝试恢复旧代码与 profile，回退失败单独报告。
- 失败后明确重试使用新的控制任务和当前配置快照；同一任务恢复时，未完成快照与当前配置有冲突则拒绝继续。即使新版本链接已被选中，回退失败仍保持为错误，不能仅凭版本号显示成功。
- 更新器和 helper 不读写核心目录内 SQLite、WAL、SHM、人格或任务，不进行核心迁移；额外依赖、安装 hook、数据路径改变或目标变更拒绝自动升级。既有源码保留，不通过 `git pull` 覆盖。
- 真实 Desktop 官方 CLI smoke 使用临时 `DSH_HOME`／profile，验证同名 `add` 能切换插件链接，旧源码、其他插件和配置保留，核心哨兵文件逐字节一致；测试插件运行入口没有执行。
- Edge 无头预览覆盖最新版本、待退出与下载失败重试，并保留核心 JSON 真实下载、窄屏及深浅色验证；JavaScript 错误 0，590px 无横向溢出。预览只使用演示数据。

### 验证边界

真实 GitHub 版本检查与 blob 下载只到内存，没有安装或执行网络下载的代码。隔离官方 CLI smoke 与生产 DSH 自动更新分别记录；此次没有对生产 Ghost 执行自动更新、卸载、核心迁移或强制重启，活跃任务继续保留。

普通 Node 在没有 `DSH_SDK_ROOT` 时明确跳过的两个真实宿主测试不计通过。等待退出、失败恢复及核心保留的隔离测试不能代替生产窗口正常重载后的完整升级验收。

内部流程见 [插件更新](UPDATES.md)。

## 0.4.0 人格沉淀与修正

日期：2026-10-27。语法检查通过；普通 Node 测试 158 项通过、2 项真实宿主测试明确跳过；本机实际 DSH SDK 全量 160 项通过，0 失败、0 跳过。

测试使用合成对话与隔离临时数据。沙盒禁止了原有重命名和 junction 测试操作，已在常规运行环境完成复核；未修改生产凭据、重置记忆或中断 DSH。

### 验证场景

- 同一窗口中相隔时间的真人交流可以形成偏好；短时间多开窗口、重复消息与固定时间桶边界不能刷出三次独立经历。
- 已形成倾向不会被一句反向要求或单条异常时间记录骤然覆盖；反复、近期且有来源的反馈可以逐步修正。
- 没有新证据时反复归纳、重新装配上下文和重启保持一致；无关消息不重复加深行为参数。
- 内部行为倾向的来源、步幅和数值范围受到限制；模型、工具、推演、引用、假设及权限诱导不能冒充真人反馈，否定不会被反向学成正向偏好。
- 三次独立的定向否定可以撤回旧风格为中性，不猜成对立风格；再次明确支持可恢复。撤回来源与当前状态进入模型上下文，且重启不漂移。
- 所有公开特征的证据包含在有界总证据集合中；有效来源缺失时不保留无依据的推断。
- v1 三个同时发生的会话所支持的旧人格仍可追溯保留；混合 v1／v2 账本、旧检查点、同一 Ghost ID 与原批准 traits／settings 保持有效。
- 停用时不追加人格升级；开启后只追加一次；人格更新失败时原始事件与状态一起回滚；规则版本与记录不匹配时拒绝恢复。
- 编程、园艺及新增主题的关注实际影响 60 天以上快照，兼容旧标识；查询不能改变快照，模型不能伪造其原文来源，字节预算保持有效。
- 既有任务、承诺、记忆分层、身份恢复、真实 SDK／HTTP、核心导出及隔离卸载继续回归。

### 验证边界

时间模拟和确定性重放不能代替连续运行数十天的真实模型表现评估。v2 是规则驱动的人格观察，不是开放式训练或主观意识证明。15／60 天仍只控制召回表示，原始事件仍保留。

普通 Node 中明确跳过的真实宿主测试不计通过。生产 DSH 的运行任务继续保留，不为本次验证重启、重置或卸载；正常重新加载后的实机表现另行验收。

内部语义见 [人格沉淀与修正](PERSONALITY_GROWTH.md)。

## 0.3.0 主体状态升级

日期：2026-10-26。`npm run check` 通过；普通 Node 测试 125 项通过、2 项真实宿主测试明确跳过；`scripts/Test-Desktop.ps1` 使用本机实际 SDK，127 项通过、0 失败、0 跳过。

新增验证包括真实 ToolRuntime 注册、按执行会话调用、版本冲突拒绝、停用／卸载清理，以及主体迁移、恢复、部分完成与旧取消证据的回归。所有数据库与任务均为隔离测试数据，没有对生产 Ghost 执行重置或卸载。

### 验证场景

- 同一 Ghost 的多个对话分别保存工作关联，共享持续身份与任务；新对话不重新创建人格。
- 已提交原始事件与主体状态在同一事务内提交，主体更新失败时事件、版本与状态一起回滚；重复事件不重复建任务。
- 回复前上下文装配只读，重复装配或模型重试不写入新经历；回复后只从授权可见输出记录带模型来源的承诺或报告。
- 任务、承诺与进展具有来源；模型宣称完成不自动成为已验证完成，模糊指代不会误改另一个对话的任务。
- ghost_state／ghost_task 在真实宿主工具服务下注册并遵守会话范围；关闭、只读诊断或卸载排队时不能写入。
- 两个对话同时读取主体版本后，迟到或重复的任务更新被拒绝，不覆盖较新状态。
- 最新用户消息决定建任务及状态更新依据；混合旧请求与最新取消证据不能重建任务。部分完成只记进度；模型的完成／取消均保留为报告。
- 旧 schema 1 数据通过追加方式初始化主体，原 Ghost ID、历史账本哈希和检查点不变；重启按来源确定性重放，不导入旧 DSH 历史。
- 未完成任务和承诺不随 15／60 天记忆分层或容量限制静默丢失；核心导出包含主体状态及其来源记录。
- 既有身份成长、记忆、恢复、HTTP 鉴权、核心导出与隔离卸载测试继续回归。

### 验证边界

真实 SDK、隔离 HTTP、工具注册、浏览器预览与真实模型工作流程分别记录。没有 DSH_SDK_ROOT 时跳过的宿主测试不能计为通过；不能以 mock 工具调用代替真实宿主注册验收。

本次不宣称已接管 DSH agent driver、模型选择或工具审批；不包含后台自主执行，也不以状态连续性证明主观意识。生产 DSH 的运行任务继续保留，正常重新加载后的实机表现另行验收。

内部语义见 [主体状态运行层](SUBJECT_RUNTIME.md)。

## 0.2.0 历史验证记录

日期：2026-10-26。README 为中英双语原理简介，本文件记录实现与验收边界。

### 验证结果

- 语法检查：npm run check。
- 真实 Desktop Node / SDK：scripts/Test-Desktop.ps1，84 项通过，0 失败，0 跳过。使用独立 Electron Node 进程与临时测试数据，不结束桌面任务、不使用生产凭据。
- 普通 Node：npm test；无 DSH_SDK_ROOT 时两个真实 SDK / HTTP 测试明确跳过，不计通过。
- Edge 无头渲染：preview/check.mjs，验证启动／关闭、内部身份不外露、核心 JSON 真实浏览器下载、卸载预览／取消／精确确认、等待退出状态、590px 与深浅色。JavaScript 错误 0，无横向溢出。仅内存演示数据。

### 覆盖

稳定 Ghost ID 与状态恢复、幂等去重、来源区分、子代理与注入排除、事务失败回滚、强制中断恢复、账本和事件篡改诊断、同机双写保护、一致备份。

新增：默认关闭、一键启动所有未来可见聊天、关闭后停止采集和上下文、跨聊天同一人格、三个独立真人会话的证据归纳、身份成长事务与重放、旧 schema 1 账本追加升级、15／60 天边界、显著性排序、有限预算、公共事实核验提示、私人重构与来源锚点、查询无关的关注快照、快照仅来自用户记录、完整核心导出。

卸载隔离测试覆盖：预览只读、过期和状态变化拒绝、确认短语和删除同意、先停 Ghost 再排队、等待 Desktop 正常退出、官方 CLI 失败保留数据、残留链接拒绝删除、只删除已确认的自有文件、部分删除重试、活跃写入者保护、路径替换与 junction／symlink／dangling marker／源码树保护。没有对真实生产记忆执行卸载。

真实 Host 测试使用实际 Cordis、SessionStore 和 SystemPrompt；真实 HTTP 测试使用实际 WebServer、Connection 与临时 LocalCredentialProvider，覆盖 401／303／200／403／405／415／400／413／404。

### 实现边界

- 人格为可追溯的规则归纳，没有训练神经网络。低风险关注／表达观察可以自动追加；权限和行为边界不会随聊天改变。旧手工人设保留在历史，当前上下文使用学习观察。
- 15／60 天生命周期作用于召回表示。原始事件仍在本地账本中供审计和导出；不是按天擦除磁盘。梗概以日期、主题和来源概括，关注快照为最多一条、240 字以内的原文瞬间／情景片段，不是图片。
- 记忆候选按当前查询、时间、用户明确重要性、重复主题和表达线索排序；当前人格关注影响快照选择。无需额外模型请求，不读取旧 DSH 历史。未验证大规模性能，规则仅覆盖有限主题，召回可能漏失。
- 当前人格摘要、关注、表达倾向和内部 trait 随旧事一同注入当前 LLM。私人经过／问题的补全属于模型推演，不另存为用户证据；模型回复始终保留 assistant 来源。
- 公共事实核验依赖当前 DSH agent 可见且可用的 web_search / web_fetch 与 provider。Ghost 通过上下文要求可靠来源、URL 和未核验标记，不包含独立联网事实核查器，也不能保证任意模型遵守提示。不得将私人记忆、私人姓名或原话拼进查询／URL。
- 核心导出为有版本和 SHA-256 的 JSON，含人格、原始事件、账本与检查点，不含宿主配置或凭据。它包含私人记忆，应由用户保管。暂未提供跨设备导入 UI。
- 完全卸载仅移除当前 Desktop profile 的 Ghost，删除本次批准目录内自有数据。手工导出、外部备份、其他 profile、源码与 GitHub 保留；系统共享锁文件不含记忆。官方卸载后若磁盘清理失败，隔离 helper 保留故障信息，不能保证插件 UI 仍可重试。
- 新版追加 identity_growth 账本类型。旧程序不能安全写入此类账本；回滚需要升级前备份，未知 schema 仍拒绝猜测迁移。

### 本机安装状态

当前 Desktop profile 的 dsh-ghost junction 指向此项目，源码和包版本已更新至 0.2.0。DSH 后台进程仍运行，遵照用户此前指示保留，不强制终止或重启。生产窗口在正常重启前可能仍运行旧代码。

尚未验收：生产窗口重载后的页面往返、真实模型连续聊天的回忆质量、公共事件引用可靠性与幻觉率、万级事件性能、跨设备安全迁移。隔离 SDK、HTTP 与浏览器预览不能代替这些验收。
