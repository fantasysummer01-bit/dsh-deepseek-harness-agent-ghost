# 第一阶段：可调整的 DSH 插件与可靠状态

## 交付范围

1. `lib/core.js`：独立 SQLite 核心，身份、状态版本、授权新消息、幂等、账本、检查点、校验和恢复。
2. `lib/index.js`：DSH Host 插件，注册受宿主鉴权的 Connection RPC；观察真实可见消息；提供有界上下文。核心失败应保留诊断，基础聊天继续运行。
3. `lib/client.js`：在原生设置侧栏注册 Ghost 页面，编辑身份、性格、目标、采集范围与字节预算，提供检索、检查点和导出。
4. 本地打包、安装/回滚说明和真实测试记录。

## 验收

- 重启前后 ghostId、branchId、traits、goals、版本一致。
- 进程被终止后，仅完整提交的事务保留，重复提交不重复计数。
- 校验错误只读，禁止静默“重新生成人格”。
- 并行写入与同机副本冲突有明确错误。
- 仅采集 `source.kind=user` 的真人文本和用户另行启用的模型可见回复；插件、工具、动态上下文均不采集。
- 默认不采集；不开新 HTTP 端口；不主动调用任何模型。
- 设置页保存有 expectedVersion，过期页面不得覆盖新状态。
- 插件安装与真实 DSH 会话验证分开记录，fixture 通过不冒称实机全链路完成。

## 数据与回滚

新数据使用插件独立目录，不探测和迁移旧 Ghost 数据。卸载仅移除插件注册，保留数据供用户决定是否删除。安装前备份 profile 的 package.json、cordis.patch.yml、cordis.yml 和锁文件；回滚时先确认文件在安装后是否被其他操作更新，避免覆盖新改动。

有未完成的 DSH 工作时不强制重启宿主。设置页能加载后，采集仍需用户自己开启。自动巩固、来源删除传播、跨设备迁移和小网络均属于后续阶段。
